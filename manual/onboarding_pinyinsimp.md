# 寫給搜狗拼音/昇陽拼音/智能狂拼/紫光拼音的使用者

> 本文對應唯音輸入法 4.6.3 版起搭載的「狂拼模式」。

唯音輸入法自 4.6.3 版開始搭載「狂拼模式」（Furious Typing Mode）。該模式專門服務於那些習慣了「搜狗拼音（Sogou）」「昇陽拼音（SunPinyin）」「智能狂拼（ChineseStar）」或「紫光拼音/華宇拼音（Unispim）」連續組句輸入的使用者：**啟用之後，連續敲擊拼音字母即可組句，無需逐音節敲聲調或空格鍵確認**。

值得一提的是：上述其他輸入法僅支援漢語拼音、簡體中文打字、陸規審音。唯音輸入法的原廠辭典索引是以漢語注音構築的。得益於 Tekkon 鐵恨注拼引擎的功能豐盈度，唯音輸入法的拼音模式（包括對此服務的狂拼模式）允許您在使用除了漢語拼音方案以外的其他（受鐵恨注拼引擎支援的）拼音方案時也能享受到上述其他輸入法的體驗。

> 唯一差異恐怕就是「遞交（上屏）」這個行為的觸發按鍵變成了 Enter 鍵，因為空格鍵承擔了太多重要的職能。

## 1. 啟用方法

該功能目前**僅對拼音輸入（任一拼音排列）生效**，對磁帶、逐字選字（SCPC）、內碼、漢音鍵盤符號與羅馬數字等輸入方法不適用。也就是說，您需要先確認唯音的輸入排列是漢語拼音等拼音排列（在「輸入法選單 → 唯音輸入法偏好設定 → 鍵盤」內選擇），且沒有啟用磁帶模式或逐字選字模式，狂拼模式才會起作用。

要啟用的話，配置方法如下（缺一不可）：

1. **「輸入法選單」→「唯音輸入法偏好設定」→「行為設定」→ 最下方（或位於 E 分頁的）的「啟用狂拼模式（連續拼音打字）」**。該開關**預設為啟用**；如果您覺得不需要、或者打字時想要恢復傳統的「逐音節敲聲調或空格確認」的行為，將其關閉即可。
2. **「輸入法選單」→「唯音輸入法偏好設定」→「鍵盤設定」→ 將上方的「注音排列」換成您想要的拼音輸入方案**。
3. **「輸入法選單」→「唯音輸入法偏好設定」→「鍵盤設定」→ 將上方的「基礎鍵盤佈局」換成「ABC」美規鍵盤佈局或其他西文佈局**。

## 2. 基本用法：連續敲拼音即可組句

狂拼模式的核心體驗是「**連續輸入、即時組句**」：您不需要在每一個音節敲完之後再敲聲調鍵（1–5）或空格鍵來確認，直接連續敲擊拼音字母即可。組字區會即時顯示語言模型試算出的整句猜測。

舉例來說，您想輸入「世界」：

1. 直接敲 `shijie`，組字區會立即顯示「世界」；
2. 如果組字區猜對了，直接接著輸入下一句即可——唯音會在前文結束時自動遞交；
3. 如果組字區猜錯了（比如顯示「時節」），見下文的「就地選字」。

這種「先連續敲、後回頭改」的輸入節奏，與搜狗拼音、智能狂拼的連續組句習慣一致。

## 3. 就地選字：Shift＋選字鍵

狂拼模式下，當組字區尚有**未完成的拼音**時，輸入法會在組字區尾段顯示一個**常駐候選窗**（copilot 候選窗），列出語言模型針對當前未完成讀音試算出的候選字詞。此時可以**按住 Shift 的同時敲選字鍵**（即您慣用的候選選擇鍵，如 1–9 或 QWERTY 排列對應的選字鍵）來就地選字、修正組字結果。

- 候選窗的第一列通常就是語言模型的最佳猜測（置頂預覽）；
- 在候選窗顯示期間，原始拼音會改以提示框（tooltip）顯示；候選窗顯示時提示框會自動讓位、避免重疊；
- 候選窗的角落會顯示「⇧」提示，提醒您需要按住 Shift 才能就地選字——這是為了避免與拼音字母輸入互相干擾（拼音字母與選字鍵可能重疊）。

> 與搜狗拼音、智能狂拼相比，唯音狂拼模式的候選窗選字需要**同時按住 Shift**。這是為了保證「拼音字母照常輸入」與「選字」兩種操作不會互相衝突——直接敲選字鍵會被當作拼音字母輸入，唯有 Shift＋選字鍵才會觸發選字。

## 4. 空格鍵的語義：插入讀音

狂拼模式下，**空格鍵的行為會暫時改變**：

- 當組字區尚有未完成的拼音時，按空格鍵會把**當前讀音插入組字器**（整組聲調候選桶一併插入、保留後續選字的自由度），**不再兼任候選輪替**；
- 當注拼槽內沒有未完成的拼音時，空格鍵恢復原本的行為（呼出選字窗、或按您在偏好設定內指定的空格鍵行為）。

這與搜狗拼音「空格確認當前候選」的習慣不同：在唯音狂拼模式中，空格是用來「把還沒打完的讀音先定下來」、方便您接著輸入下一個音節，而不是「把當前組字結果遞交出去」。

## 5. Enter 鍵的語義：固化讀音、停留組字

狂拼模式下，**Enter 鍵的行為也會暫時改變**：

- 當注拼槽尚有未完成的拼音時，按 Enter **只會固化當前讀音**（如果有高亮的候選，則就地確認該候選），並**停留在組字狀態**，不會把整個組字區的內容遞交出去；
- 當注拼槽清空之後，**再次按 Enter** 才會遞交整個組字區的內容。

也就是說，狂拼模式的 Enter 是「兩段式」的：第一下 Enter 釘住當前讀音、第二下 Enter 遞交整句。這樣可以避免「unfinished reading 存在時誤按 Enter 就把整句交出去」的意外。

## 6. 長詞與多音節詞的輸入

狂拼模式的組句引擎（語言模型）會自動處理多音節詞的切分與合併。您可以直接連續敲擊完整的拼音，也可以**用空格把不確定的讀音分段固化**：

- 直接連續敲 `xian` 或分段敲 `xi ␣ an ␣`，語言模型都會試算、並在分數允許時合併出「西安」這類長詞；
- 固化進組字器的讀音仍可被語言模型引導的重切分涵蓋，因此「分段固化」不會鎖死後續的組句。

## 7. 與其他輸入法的對照

| 習慣 | 搜狗/昇陽/狂拼/紫光 | 唯音狂拼模式 |
| - | - | - |
| 連續敲拼音即可組句 | 是 | 是 |
| 逐音節敲聲調確認 | 不需要 | 不需要 |
| 候選窗就地選字 | 直接敲選字鍵 | **Shift＋選字鍵** |
| 空格鍵 | 確認候選/上屏 | 插入當前讀音（注拼槽非空時） |
| Enter 鍵 | 遞交原始碼 | 固化讀音＋停留組字（兩段式） |

## 8. 注意事項

- 狂拼模式僅在拼音排列（且未啟用磁帶／SCPC）時生效；注音排列下該開關無效。
- 就地選字的候選窗僅在「組字區尚有未完成拼音」時顯示；讀音全部固化後，選字走正常的選字窗流程。
- 如果組字區的顯示與您的預期不符，可以先按 ESC 清空整個組字緩衝區、重新輸入。
