# 輸入與設定問題

### 問：有沒有ㄅ半模式？我用習慣了小麥注音或香草的「傳統注音」模式的候選字順序，請問我該怎麼辦？

最快速的方法：「唯音輸入法偏好設定」的「一般設定」頁面有「我姓ㄅ」按鈕，點一下之後根據提示操作即可。

在此基礎上，要來回切換的話，請摁 Ctrl+Command+Shift+P 來啟用ㄅ半模式。這在唯音當中被稱為「逐字選字模式」。

> 唯音這邊沒有直接集成使用過「小麥注音的」候選字順序，而是使用了對ㄅ半輸入法使用者而言更具肌肉記憶之意義的「倚天中文 DOS 候選字排序」。**該排序僅對逐字選字模式有效**。
>
> 因為ㄅ半輸入法的使用者群體不太會再去適應新的排序，所以唯音輸入法從 3.6.1 版開始移除了對ㄅ半輸入法的候選字排序自訂功能。
>
> 至於小麥注音與 OpenVanilla 香草輸入法用的排序是不是也是倚天中文 DOS 排序，請自行詢問對應的輸入法團隊（雖然有一些現任成員是重複的）。

### 問：我用了十幾年微軟新注音，唯音能繼承我的打字習慣嗎？

可以。唯音的原廠預設值已經照顧到絕大多數「新注音肌肉記憶」的需求，另有幾個開關值得您手動調整：把「**選字游標:**」改成「**將游標置於詞語後方**」、把「**選字窗佈局:**」改成「**縱向佈局**」、用 `⇧←`／`⇧→` 標記範圍後敲 `⏎` 就地加詞、並在「混合輸入」區啟用「啟用中英混合輸入回退」與「啟用中英混打模式的英數閂滯狀態」。

完整清單與逐項說明請見《[寫給微軟新注音的使用者](../onboarding/onboarding_msnewphonetic.md)》。

### 問：「選字游標」的「前方／後方」到底是什麼意思？跟別的輸入法講的「前／後」對不上欸。

唯音的術語一律以**字詞**為參照，並使用 **front／rear（前方／後方）** 這組不會含混的說法：

- 「將游標置於詞語前方」＝選字時游標停在詞語的前緣（macOS 內建注音習慣）。
- 「將游標置於詞語後方」＝游標停在詞語的尾端（Windows 微軟新注音習慣）。

您會覺得對不上，是因為早年奇摩輸入法與小麥注音用的是「before／after」這類相對式的說法（zonble 等人的命名慣例）：小麥的程式把該選項實作成「候選字詞落在游標的哪一側」（`selectPhraseAfterCursorAsCandidate`）、診斷資訊也印作 `Before Cursor／After Cursor`；奇摩的組句器 Manjusri 則以「游標與字塊的相對位置」表述（`cursorAtEndOfBlock`——游標在字塊上或緊前＝微軟式；游標在字塊末端＝蘋果式）。同一件事，小麥拿「字詞」當主語、奇摩拿「游標」當主語；而這組詞的多義性又太強——單看字面既能按空間前後去讀、也能讀成先後順序，很難讓人精準還原它想表達的方位。加上兩邊把同一個品牌貼在相反的「前／後」字樣上（奇摩：「游標在**前**＝微軟新注音輸入法模式」；小麥：「游標**後面**＝像微軟新注音」），任誰來讀都只能雞同鴨講。唯音因此在 v1.5.3 版把這套說法整個換掉，改用把參照物講明白的「文字書寫方向順序上的」 **front／rear（前方／後方）**：一律相對於**字詞**——游標停在詞語的前緣，還是停在詞語的尾端。

實務上請**以行為為準**（後方模式＝游標停在詞尾），並以偏好設定內的選項字樣為準；各家輸入法文件裡的「前／後」都可能與唯音相反。要動手調整的話，位置在「偏好設定 → 選字設定 → 游標與選字窗定位」的「**選字游標:**」。

### 問：怎麼敲簡體？

請在系統偏好設定內新增「唯音-簡」這個輸入法。只要系統內有安裝了唯音輸入法，就應該能在簡體中文輸入法分類下找到該輸入法。為什麼不像其它有些輸入法那樣直接做熱鍵開關呢？因為他們那樣無法做到在簡體輸出時讓 macOS 聽寫的內容「也是簡體中文」。

唯音不信任繁簡轉換與簡繁轉換，因為必然會有轉換錯誤發生。唯音的簡體中文模式使用單獨的原廠辭典、與繁體中文模式的辭典分隔開。然而，每次在新增使用者片語辭典時，唯音都會往另一個繁簡模式的使用者片語辭典內添入轉換過的結果。因轉換過的結果的正確性無法保證，所以任何轉換結果的所在行都會有行尾標記。

唯音的繁簡切換熱鍵是 Ctrl+Command+Shift+D。更舊版的唯音輸入法沒有專門的繁簡切換熱鍵。

### 問：符號選單很多符號都顯示成被方框框起來的問號，該怎麼辦？

唯音只是允許輸入這些符號而已。至於這些符號怎樣顯示，則可能需要您系統內有安裝對應的字型。

打比方說「音樂」這個符號分類，就需要您安裝 [SMuFL](https://w3c.github.io/smufl/latest/index.html) 標準的樂譜排版字型。如果您有安裝過 Steinberg Dorico 的話，您系統內應該已經有安裝 [Bravura](https://github.com/steinbergmedia/bravura/releases/tag/bravura-1.380) 這款字型。您也可以安裝 MakeMusic 出品的 [Finale Maestro SMuFL](https://makemusic.zendesk.com/hc/en-us/articles/1500013053461-MakeMusic-Fonts-and-Licensing-Information) 字型。

另外，「注音」符號分類下，可能會有至少四個缺字，需要您安裝任何可以支援[粵語注音標準](https://www.unicode.org/L2/L2019/19100-cantonese-bopomofo.pdf)的字型（比如 [NotoUnicode](https://github.com/MY1L/Unicode/releases) 或者 [一點明體 I.Ming](https://github.com/ichitenfont/I.Ming) 都可以）。

此外，macOS 內建的字型對某些萬國碼字元的顯示支援也會隨著 macOS 版本的不同而有異動。

### 問：選字窗可以改成 macOS 內建注音那種橫版陣列型選字窗嗎？

田所選字窗現在已經支援這種多行橫版派列了。嚴格來講，這不是陣列排列，因為每一行的候選字數量的多寡取決於這一行的總體的繪製長度。

題外話：唯音輸入法已經自 3.5.4 版開始已經移除 IMK 選字窗。

> 很多使用者都希望能在自己喜歡的副廠輸入法內用上 IMK 的矩陣選字窗（就是 macOS 系統內建的注音輸入法的橫版矩陣選字窗）。然而，經過研究，唯音輸入法團隊不得不認清（目前能推斷出來的）唯一可能事實：IMK 選字窗充其量也只是 Apple 用來滿足自家輸入法需求的產品部件、一開始就沒有讓副廠輸入法廠商用得爽的打算。第三方輸入法開發者們想要將 IMK 選字窗實作到企業級堪用的地步的話，往往需要使用私有 API 等強硬手段、也不見得就一定能做到這個地步。如果你們有誰認識在 Apple 的人的話，請他們關注 Bug Report #FB11300759，這樣 Apple 或許能稍微重視一下這些問題。至少，就 IMK 選字窗的功能實作而言，唯音已竭己所能。

### 問：偏好設定內的鍵盤佈局與注音排列設定很亂欸。該怎麼調整？

只需要注意：

- 想用大千傳統 / 倚天傳統 / 漢語拼音的話，偏好設定介面內有對應的快速設定按鈕。
- 對於注音而言，只需要設定「排列」即可：在使用注音排列的情況下，鍵盤佈局設定僅會影響到螢幕小鍵盤的顯示。

### 問：有沒有辦法迅速備份/恢復輸入法的偏好設定？

唯音允許使用者使用終端機將當前輸入法偏好設定的絕大多數內容傾印成一份備份檔案。該備份檔案的實質是 Shell 腳本、需要在終端機內使用 pipeline 語句來指定寫到哪個新檔案當中（否則只會在終端機螢幕上顯示一遍腳本內容）。只需要將該腳本直接在終端機內運行、就可以將該檔案內的輸入法偏好設定恢復到電腦當中。命令用法參考範例：

```sh
~/Library/Input\ Methods/vChewing.app/Contents/MacOS/vChewing --dump-prefs > ~/Downloads/vChewingPrefBackup.sh
```

需要注意的事項有：
  1. 任何涉及到檔案路徑的偏好設定內容均不在備份範圍內，因為會有 Sandbox 資料位置存取相容問題。因為 Sandbox 機制的存在，唯音輸入法在存取一個手動指定的目錄時必須由使用者藉由圖形介面親自點開這個資料夾/檔案才可以（將檔案拽入到路徑控制項內也可以，因為也是使用者親自在圖形介面操作）。
  2. 該功能的設計交互特性決定了該功能不適合用來製作圖形介面版本。如果您希望將這個備份恢復過程自動化的話，您或許可以借助其他的輔助工具（比如 crontab）搭配您自己寫的其它 Shell 腳本工具來一同使用。
  3. 如果您用的唯音輸入法是您自己組譯建置的版本的話，請簽名，否則該命令可能會用 NSLog 的形式抱怨說簽名資料不存在。這並不影響傾印過程。

另：偏好設定視窗的「開發道場」頁面也提供了圖形介面的偏好設定 JSON 匯入 / 匯出功能——可以直接點按「匯出」按鈕將偏好設定存成一份 `vChewing_Preferences.json`，需要恢復時再點按「匯入」按鈕選取該檔案即可：

- 交換範圍：涉及沙箱安全權限的路徑設定與介面語言設定不在交換範圍內；除此之外的絕大多數偏好設定內容均涵蓋在內。
- 匯入完成之後會顯示成功筆數與失敗筆數，並列出每筆失敗的鍵與原因。
- 自唯音 4.7.3 版開始，在古早系統版本下使用該功能時，使用者會被提示改採其他交互方式來匯入 / 匯出 JSON（此時可以改用本節前述的終端機方式）。

### 問：怎樣才能繞過組字區直接輸入大寫或小寫英文字母？

偏好設定內有相關設定，要求唯音版本至少 v1.9.0 SP1。

唯音鼓勵使用鍵盤右側的 Shift 直接切換至英數輸入模式。

如果您在用的基礎鍵盤佈局是「Apple 倚天傳統」或者「Apple 大千傳統」的話，還可以這樣：

- 摁住 Option+字母鍵 可以「在組字區沒有字的情況下」直接輸出小寫字母。
- 摁住 Option+Shift+字母鍵 可以「在組字區沒有字的情況下」直接輸出大寫字母。

### 問：中英混打時，我不想每次只是為了遞交英文就得按一堆修飾鍵。

請在「偏好設定 → 行為設定 → 混合輸入」開啟「**啟用中英混打模式的英數閂滯狀態**」（位於「啟用中英混合輸入回退」正下方；出廠預設為關，母選項沒開時完全無作用）。開啟後，一旦混打模式把某段英數內容判定為英文，該段就會立刻遞交、並把這個判定結果「閂滯」住：其後敲下的每一顆可列印 ASCII 字元都直接送出，不再於輸入法內累積等待確認，打一整串英文的手感因而接近真正的英數模式。

要留意的是：內容一旦遞交出去就無法回收，BackSpace／Delete／Esc 只會解除閂滯、既不送出也不刪除任何字元，所以不能撤銷已經打出去的英文；上鎖之後，連本應被當成注音的按鍵也會被當成 ASCII 送出（例如 `hel` 上鎖之後再敲 `su3`，得到的是 `hellosu3`）。這項設定因此不適合頻繁中英往返、逐段確認的打字習慣；它也不會真的把唯音切成英數模式，而且只作用於英文，拼音／磁帶模式不適用。

細節（含解除鍵清單）見《[偏好設定](../manual/preferences.html#混合輸入)》。

### 問：中英混打時我習慣「不照順序敲注音」（例如大千聲韻並擊），新的判定讓我不習慣。

v4.8.4 版新增的「**依槽序鍵入判定讀音**」就是這個判定的開關（預設開啟，位於「啟用中英混合輸入回退」正下方，僅該母選項開啟時有作用）。維持開啟（即 v4.8.3 版起的新制）時，判準是「按鍵是否依正規鍵序敲成了一個讀音」、交由注拼引擎判定：`ls`、`ln` 這類不可能依正規鍵序成讀音的純英文字母會被視為英文意圖、如實遞交；大千 26 的 `qquu`（＝ㄅㄚ）仍會被吸收為單一讀音。

關閉本項則回到舊制：兩字母的純英文（`ls`）會被重新吸收成注音讀音（敲空白鍵會叫出該讀音的候選字），大千 26 的 `qquu` 會留在英數暫存區、敲空白鍵時如實送出 `qquu `。本項不影響「英數閂滯狀態」自身的判定。

建議：除非您明確需要「混打時不必照槽序敲注音」的彈性，否則請維持開啟本項。

### 幹：我是拼音派的/簡拼注音派的，想知道這個輸入法是否可以免打聲調。

可以，但僅限**拼音打字模式**（需唯音 v4.4.0 開始的版本）；**注音打字模式**目前沒有這個特性。

拼音打字模式下，空格鍵的語義是「省略聲調」，而主鍵盤區的數字鍵「1」仍然代表陰平聲調。您可以直接把整句的拼音連續敲完、不必逐個音節打空格或聲調，例如「shijie」會自動被切分並組出「世界」。只有在遇到歧義場合時，才需要補空格或聲調來劃分音節：比如「企鵝」至少要敲成「qi4e」或「qi e」。

- 注意：免聲調連打會讓組字引擎面對的候選組合數量暴漲。所以，免聲調的 4 音節（含）以下長詞仍可整詞連續敲擊組出；5 音節以上的免聲調連打則需要藉由聲調或空格鍵來劃分音節。這個限制是為了防止組字引擎被笛卡爾積噎死（會連帶噎死整個桌面）——這是與「免打聲調」這種使用者需求共生的數學難題。
- 如果您是「簡拼」的愛好者（只敲聲母等不完整讀音來組詞）的話，請在偏好設定的「行為設定」頁面開啟「狂拼模式」（需唯音 v4.6.3 開始的版本，會預設開啟）。狂拼模式就是專門服務您這種需求的：自 v4.7.0 版開始支援簡拼整詞，例如直接敲「ysxb」就會給出「野獸先輩」；當頂級簡拼整詞候選明確勝出時，打字即自動套用、不必等 Shift+選字鍵確認。詳細用法請見《[寫給搜狗拼音/昇陽拼音/智能狂拼/紫光拼音的使用者](../onboarding/onboarding_pinyinsimp.md)》。

至於**注音打字模式**：唯音的注音打字不支援簡拼（每個音節都必須完整輸入注音符號），每個音節的聲調也必須輸入（一聲可用空格鍵輸入）。如果您對上述特性有剛需，請切換到拼音打字模式來用（熱鍵：Ctrl+Command+Shift+J 可在拼音／注音打字模式之間切換）。

### 問：我想使用三列注音，不想重複擊鍵，只是（比起通用拼音跟韋氏拼音）我更熟悉漢語拼音，該怎麼辦？

如果您在用唯音 v3.4.8 開始的版本的話，您可以嘗試使用[劉氏注音排列](../manual/arranges.html#劉氏擬音注音排列-alvin-liu---imitative)。

### 問：使用者自訂辭典檔案頭部那串奇怪的 Pragma Header 是？砍掉又會冒出來，是病毒嗎？

那是唯音輸入法的自動格式整理標記，正常情況下可以不用理會。如果遇到辭典檔案內容無法正常生效的情況的話，請砍掉這一行 Pragma Header 且存檔，此時輸入法會自動重新整理格式、且會在此之後補回這一行。

### 問：要怎麼輸入符號、特別是全形空格？有標點符號小鍵盤嗎？還有沒有別的可以隨選符號輸入的方法？

當且僅當組字區內沒有內容的情況下，摁 Shift+Space 可以連續輸入全形空格。

標點符號小鍵盤的功能沒有製作，因為製作成本與功能易用性回報相比實在不值得。請善用波浪符號選單，能提供與新酷音輸入法的波浪符號鍵選單近乎一致的體驗。如果將新酷音的 symbols.dat 放入使用者片語辭典目錄的話，則波浪鍵選單的內容會與新酷音完全一致。如果想用類似於小麥注音的符號選單的話，請摁「Option+波浪符號鍵」。如果您用的是 JIS 鍵盤的話，因為 JIS 鍵盤沒有波浪鍵，所以唯音會改認位於右手 SHIFT 鍵左側的「_」鍵作為符號鍵、以取代波浪符號鍵。

### 問：我想在打注音時迅速敲全形或半形數字，怎麼辦？

在**組字區空著**、且未啟用「半形標點模式」時：

- 摁住 `Option` 敲主鍵盤數字區：遞交半形阿拉伯數字。
- 摁住 `Option+Shift` 敲主鍵盤數字區：遞交全形阿拉伯數字。

若您啟用了「半形標點模式」（預設熱鍵 ⌃⇧⌘H），這套便捷輸入會整條停用：唯音不再攔截該按鍵、而是直接放行給當下的系統鍵盤佈局，此時同樣的按法得到的是半形數字。另：主鍵盤區之外，「數字小鍵盤」另有獨立偏好「**數字小鍵盤:**」（六種行為，出廠預設為「始終以半形文字直接遞交」），可於偏好設定內調整。

詳見《[文字切換(半形/中英...)](../manual/toggles.md)》。

### 問：請問有學習常用詞彙的功能嗎？

預設的漸退記憶模組只有不到六天的有效記憶，且會有個別記憶觀測失效導致的「記不住」的情形。想要持久記憶的話，可以隨時用 SHIFT+前後方向鍵 來選中您想要手動記憶的詞彙、再摁 Enter 添入使用者片語辭典。

### 問：選字鍵可以改 ASDF 之類的嗎？

唯音輸入法預設的選字窗可以修改選字鍵：在偏好設定「選字設定」頁內可以改，輸入的選字鍵序列會被自動去重複、再做合規性判定。

唯音輸入法已經自 3.5.4 版開始移除 IMK 選字窗、也不再提供；偏好設定的「選字設定」頁面內只留有一顆「IMK 選字窗去哪裡了？」說明按鈕。所以，上述這些與選字窗有關的自訂功能都僅適用於田所選字窗。

### 問：請問可以自己增加字庫嗎？

請善用輸入法選單內的使用者片語自訂功能；也可以在「偏好設定 → 語彙編輯」內選擇「自訂語彙」逐條新增，格式為 `詞語 讀音-讀音 [權重]`。此外，打字時可用標記模式選取詞語範圍後、叫出選單新增。

### 問：為什麼選字窗裡某些字的位置跟我記憶中的不一樣？

請確認「偏好設定 → 辭典設定 → 對所有單漢字候選字強制施加倚天中文 DOS 系統排序」是否開啟（預設開啟）。開啟時，逐字選字模式下的單漢字候選字一律遵循倚天中文 DOS 的經典排序，不受打字學習功能干擾。

### 問：我不想讓輸入法一直學我打字，可以關掉嗎？

可以。請至「偏好設定 → 辭典設定 → 漸退記憶模組」開啟「急速遺忘模式」：記憶有效期限會由約一週縮短到約 12 小時。期間仍會參考這些記憶，但權重消褪極快，約 12 小時後對選字的影響便趨近於零。

### 問：為什麼選字窗裡會出現假名（日文字）？

原廠辭典內含假名音節資料。若不需要，請在「偏好設定 → 辭典設定」開啟「停用原廠假名音節資料」。如此也能避免超短的英文單詞被假名候選干擾，適合中英混打的場合。

### 問：安裝後覺得不順手，怎麼完整移除？

請見《[如何卸除唯音輸入法](../manual/UNINSTALL.md)》與《[安裝/啟用/切換/停用/卸除](../manual/install_uninstall_enable_disable.md)》。因為 macOS 沙箱（Sandbox）權限限制，卸除時需要在系統設定內手動操作。

### 問：我想打行列（行列三十），該怎麼設定？

三步：一、進入「唯音偏好設定」的「磁帶設定」頁籤，把行列的 `.cin2` 鍵碼表載入到磁帶模組內；二、把碼表放在本機目錄（例如「下載」），不要放在由 iCloud 代管的「文件」或「桌面」，以免同步延遲導致輸入法讀不到檔案；三、進入「選字設定」頁籤、以鍵盤輸入的方式把「選字鍵」自訂變更為 `1234567890`，然後在唯音的輸入法選單中只勾選「模擬逐字選字輸入」一項。

完整說明請見《[寫給行列三十輸入法的使用者](../onboarding/onboarding_array30.md)》。
