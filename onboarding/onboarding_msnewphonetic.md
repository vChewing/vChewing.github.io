# 寫給微軟新注音的使用者

**本文章節：**

- 目錄
{:toc}

---

唯音輸入法目前沒有「新注音模式」這種一鍵切換的按鈕，但您過去十幾年養成的打字習慣，大多可以在偏好設定內逐項對齊。以下幾組設定是新注音使用者最常需要動手調整的地方。

## 1. 選字游標：改為「將游標置於詞語後方」

- 位置：偏好設定 → 選字設定 → 游標與選字窗定位 → 「**選字游標:**」。
- 改為「**將游標置於詞語後方**」。出廠預設是「將游標置於詞語前方」。
- 這個選項在 App 內的字樣是「將游標置於詞語後方 // Windows 微軟新注音風格」。唯音的術語以**字詞**為參照（**front／rear**＝前方／後方）：後方模式＝選字時游標停在詞尾、且不接受橫跨游標的候選字。早年奇摩與小麥注音的「before／after」說法參照不明、兩邊的品牌標籤甚至互相矛盾，是這套術語容易雞同鴨講的根源（來龍去脈見《[常見問題](../faq/basics.md)》）；請以行為為準。

## 2. 選字窗：改用「縱向佈局」

- 位置：偏好設定 → 選字設定 → 選字鍵與佈局 → 「**選字窗佈局:**」，設為「**縱向佈局**」。
- 請保持「**始終自動展開多行選字窗**」關閉（這也是出廠預設）：選字窗剛被叫出來時只顯示單列，等到您翻頁／翻行時才展開成多列。這與微軟新注音輸入法和 macOS 內建注音輸入法的行為幾乎一致。
- 縱排矩陣佈局看上去與微軟新注音 2003 開始的佈局相似。
- 「**選字鍵:**」同時決定著每一列最多能顯示多少筆候選字，可一併調整。

## 3. 就地加詞／升頻／降頻／刪詞

這套操作體驗源自微軟新注音 2003：

- 組字之後，摁住 `⇧` 敲 `打字書寫順序上的 前後方向鍵` 標記您要處理的字詞範圍。
- 敲 `⏎` 就地加詞；如果該詞音配對已在庫，則提升其權重。
- 敲 `⇧⌘⏎` 就地降頻；敲 `⌫`／`⌦` 就地刪詞（把該詞音配對塞入語彙濾除表）。
- 標記範圍最短為 2 個字或 2 個讀音、最長為 10 個。如需對單個漢字做升權或排除，請在偏好設定的「開發道場」內開啟「允許對單個漢字進行升權或排除」權限。

細節請見《[標記狀態＆就地加詞/刪詞/控頻](../manual/markingMode.md)》與《[鍵盤熱鍵使用手冊（macOS）](../manual/shortcuts.md)》。

## 4. 中英混打：不必再切模式

- 位置：偏好設定 → 行為設定 → 混合輸入。
- 開啟「**啟用中英混合輸入回退**」，即可直接敲 `MacBook`、`4G` 這類中英夾雜的內容。
- 若您常需要一次打一整串英文，再加開「**啟用中英混打模式的英數閂滯狀態**」：一旦判定落定為英文，該段即刻遞交、其後每顆可列印 ASCII 直接送出，手感接近真正的英數模式。請注意該狀態下的內容遞交後不可回收。
- 「**依槽序鍵入判定讀音**」請維持預設開啟，除非您需要「混打時不必照槽序敲注音」的彈性。

## 5. 其他「新注音味」的開關

- 以 CpLk 或 Shift 切換中英文時，如果不想在螢幕右上角看到飄窗提示的話，可以在「偏好設定 -> 行為設定」找到開關關掉提示。
- 就地增刪詞時，被標記的內容會像微軟新注音那樣高亮顯示；不過這項視覺效果是否生效，取決於客體應用是否支援，而非輸入法本身能決定。
- 左右兩側的 Shift 鍵切換中英（兩者皆預設開啟）：這是自 Windows 轉來的中文使用者打死都不願犧牲的硬性需求，唯音預設就為您開好了。
