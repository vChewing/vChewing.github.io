# 寫給 macOS 10.6 開始的內建注音輸入法的使用者

如果您是從 macOS 10.6（Snow Leopard）開始就在用系統內建注音輸入法的人，那唯音輸入法對您來說基本上不需要重新適應——唯音的預設行為都是按照 macOS 10.9 開始的內建注音輸入法的習慣來的，包括但不限於：

- **聲調鍵覆寫字音**：摁聲調鍵可以直接覆寫游標身後的漢字的讀音音調；若發現不可析構，則直接輸入聲調符號。
- **以詞語節點為單位跳轉游標**：摁住 `Option`（Alt）的同時敲前後方向鍵（實際按鍵隨客體軟體的文字書寫方向而定：橫排時為 ←／→、縱排時為 ↑／↓），可以以候選詞的長度為單位迅速跳轉游標。
- **選字游標預設置於詞語前方**：與 macOS 內建注音相同；想改的話可在偏好設定內換成詞語後方。

> 本文對應至少唯音輸入法 4.8.7 版。

如果您想更進一步、以不完整的讀音連續打注音的話，唯音自 4.8.6 版起另有**注音狂打**（預設停用，位於偏好設定「行為設定」頁）：連續鍵入注音符號即可組句，當前音節打完而下一鍵屬於新音節時會自動成音，不必逐音節敲聲調；只敲聲母亦可（簡拼，例如 ㄍㄋㄋ 得「狗男女」），而**空白鍵仍舊是陰平鍵**、不會被挪作確認候選之用。

需要微調的話，請見《[偏好設定](../manual/preferences.md)》與《[鍵盤熱鍵使用手冊（macOS）](../manual/shortcuts.md)》。
