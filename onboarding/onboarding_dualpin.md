# 寫給雙拼使用者

> 本文對應唯音輸入法 4.9.0 版起搭載雙拼功能。

唯音輸入法自 4.9.0 版起搭載**雙拼**（Dualpin）功能。雙拼不是另一套輸入法，而是**拼音輸入的一種提速方式**：它把漢語拼音的「聲母」與「尾綴（韻母）」各映射到一個按鍵，於是**兩鍵即可敲出一個音節**——例如微軟雙拼下敲 `vs` 得 `zhong`（中）、`hk` 得 `hao`（好）。鍵位怎麼對應，取決於您使用哪一套**雙拼方案**；唯音不發明方案，只提供承載它的引擎與界面。

> 雙拼**只作用於拼音輸入**。注音輸入、磁帶模式、逐字選字（SCPC）與內碼輸入都不受影響。

## 1. 啟用方法

啟用之前，有一件事只有您能決定：**您要用哪一套雙拼方案**。配置助手會替您預選「微軟雙拼」，但您隨時可以改。方案分兩類：

- **內建**：微軟雙拼、GB/T 34947-2017（見第 3 節）。
- **自訂**：其餘方案以 JSON 方案檔散布，需您自行下載後匯入（詳見第 4.2 節）。
    - 這些方案包括「小鶴雙拼」等知名方案，均因著作權疑慮等原因無法綑入輸入法安裝包內。

以下兩種啟用方法擇一即可。

### 方法一：用配置助手（推薦）

1. 開啟《唯音輸入法配置助手》。
    - 敝站託管的線上版本，僅適用於最新版的唯音輸入法：[點此進入配置助手](../assistant/)。
    - 唯音輸入法也有同捆與自己發行版本對應的配置助手，詳見「唯音輸入法偏好設定」→「一般設定」頁面→點一下「開啟快速配置助手」按鈕。
        - 同捆版可離線使用，且保證與您當前安裝的唯音版本相配；線上版則隨時最新、但可能只適用於最新的輸入法版本。
2. 在「您主要用哪一種打字方式」一題選「**漢語拼音（雙拼）**」。
3. 助手會為您預選「微軟雙拼」、啟用雙拼模式、並沿用拼音狂打（見第 2 節）；它的後續頁面也會提醒您方案編輯器之所在、以及方案檔何處取得。
    - 您可按需取消對某些部分預設配置選項的套用。
4. 匯出配置包，回到唯音偏好設定的「一般設定」頁，按「**點此從剪貼簿匯入（由配置助手生成的）配置資料**」匯入。
    - 雙拼 Schema 的匯入過程無法藉由這一步完成（配置包只承載偏好設定，不挾帶方案檔）。詳見下文〈4.2 下載其他方案〉。

### 方法二：自己在偏好設定裡開

在「輸入法選單 → 唯音輸入法偏好設定 → **鍵盤設定**」頁內，依序確認三項（**缺一不可**）：

1. **「拼音輸入種類:」**：選「漢語拼音+數字標調」（雙拼是拼音模式之延伸，故須先站在拼音上）。
2. **「雙拼方案:」**：選您要的方案（微軟雙拼／GB/T 34947-2017／自訂雙拼）。
3. **「啟用雙拼」**：打開。

同頁的「基礎鍵盤佈局」與「英數鍵盤佈局」之選擇與您用全拼時相同，不必為雙拼另設。若您選了「自訂雙拼」但尚未匯入方案、或該方案未通過校驗，雙拼不會生效——鍵序會逕交全拼處理（這是引擎的安全退路，不是故障）。

想恢復全拼時，把「啟用雙拼」關掉即可；「雙拼方案:」之選擇會被保留，下次重開不必重新選。

## 2. 怎麼打字

- **兩鍵一音節**：第一鍵是聲母鍵（零聲母之音節另有專用鍵）、第二鍵是尾綴鍵；兩鍵湊齊，該音節的讀音就進入組音區（此時尚未遞交給您正在打字的程式）。鍵位對應可在偏好設定內之鍵位預覽圖（或方案編輯器）上一目了然。
- **聲調**：雙拼鍵位本身不含聲調，故讀音一律以**不標調**之最常用讀音進場，交由語言模型判斷。若您對某個音節的聲調有主張，仍可事後覆寫——把游標留在那個音節之後，**直接敲聲調鍵（主鍵盤數字列）**，即可就地覆寫「**游標身後那一個音節**」之聲調，唯音會給您一聲內文提示（該提示可在偏好設定內關閉）。
    - 聲調鍵一覽：`1`＝陰平（一聲）、`2`＝陽平（二聲）、`3`＝上聲（三聲）、`4`＝去聲（四聲）、`5`＝輕聲；另外 `6` 同 `2`、`7` 同 `5`，此二鍵係兼容大千傳統注音佈局之調號數字。
    - 已固化進組字器的音節同樣適用；只有讀音音節才受理——標點、阿拉伯數字等字面內容不是音節，敲數字鍵只會照常輸入數字（故雙拼下仍可連續輸入數字）。此「聲調鍵」之行為可在偏好設定內調整（見《[唯音輸入法偏好設定](../manual/preferences.md)》之〈聲調鍵〉一節）。
- **選字**：敲空白鍵確認組字區內容，或以數字鍵／選字鍵在選字窗內選字。
    - 若（副駕）選字窗提示您「摁⇧選字」，表示該窗之候選須以 **Shift＋選字鍵**選取——單按選字鍵不會生效。
- **打錯了**：雙拼以「碼」為打字單位，故**退格鍵的刪除粒度是「一個尚未固化的音節」**——按一下退格即撤掉整個剛譯出的讀音（而不是逐字母刪拼音），已經固化進組字器的音節不受影響；若只敲了一個尚未成碼的首鍵，退格同樣撤掉它。

### 拼音狂打對雙拼的影響

「拼音狂打」是唯音招牌的連續打字模式，**預設開啟**，且雙拼不另立開關——它跟隨拼音側的同一個開關（「行為設定」→「啟用拼音狂打（連續拼音打字）」）。兩態之差異如下：

- **開啟（預設）**：敲完一個音節之兩鍵後，詞幹留在組音區、您可以繼續往下敲，唯音即時以語言模型猜整句；副駕選字窗（copilot）會在您敲下**第一個鍵**時就開始列出候選。Shift＋選字鍵可就地替換游標前方那一段尚未成詞的讀音，Enter 則就地接受選字窗之高亮候選。這是最接近搜狗拼音、智能狂拼的節奏。
- **關閉**：**次鍵即成音節**——第二鍵按下的同時，該音節就地固化進組字器，唯音不做連續組句之猜測、首鍵也不彈候選窗；節奏即「兩鍵一字、逐字堆疊」，每一步都在您眼下。
    - 關掉「拼音狂打」後，雙拼的打字節奏即近似傳統之大千聲韻並擊組句（一如微軟新注音、漢音等傳統並擊注音輸入法），惟雙拼之第一、二碼順序不可顛倒。

## 3. 內建的兩套方案，與「為什麼只有兩套」

唯音的安裝包內**只綑綁兩套**雙拼方案：

| 方案 | 說明 |
| :-- | :-- |
| **微軟雙拼** | 微軟拼音之雙拼鍵位。**考場環境（CBT／iBT）與多數教材**採用者眾，也是唯音之出廠預設。 |
| **GB/T 34947-2017** | GB/T 標準之雙拼鍵位，沒有與授權有關的隱憂。 |

其餘廣為人知的方案——智能ABC、拼音加加、搜狗雙拼、紫光華宇、自然雙拼 (周志農)、小鶴雙拼、四通雙拼——**因著作權與授權疑慮，不一併綑入安裝包**。它們改以**方案定義檔（JSON）**之形式發表於唯音官網倉庫，由您自行下載、匯入使用（見第 4.2 節）。其中小鶴雙拼（含小鶴音形）之作者已明確表示不予免費授權，故唯音不同捆其鍵位方案。

## 4. 自訂方案：編輯器與方案檔

### 4.1 用內建的方案編輯器

唯音偏好設定的「鍵盤設定」頁，「雙拼方案」區塊的**最底端**常駐一座**方案編輯器**：

- 可直接編輯自訂方案之各鍵位（二十七鍵之聲母／尾綴指派）、另存內建方案為副本、匯出方案檔，並即時顯示引擎之校驗報告（錯誤 E 系列會阻擋儲存）。
- 若您手上只有別套輸入法的鍵位表，可在編輯器內逐一指定；亦可逕自手寫 JSON。

完整用法（各欄位、校驗代碼、存檔匯出與還原、舊版系統之差異、方案檔何處尋）另見《[雙拼方案編輯器](../manual/dualpinSchemaEditor.md)》。

### 4.2 下載其他方案

- 方案定義檔之倉庫目錄（可直接下載；附 JSON Schema 供驗證）：<https://github.com/vChewing/vChewing.github.io/tree/main/valueadd/dualpin-schema-files>
- 各檔之收錄政策、出處與授權，以及**如何匯入**之逐步說明：見《[唯音輸入法：雙拼方案定義檔格式標準](../techdocs/Dualpin_Schema.md)》之〈收錄之方案定義檔〉與〈如何匯入〉。

方案定義檔只是一份**純 JSON 資料**：不含程式碼、不會連網、不會被執行；唯音匯入前會先校驗，錯誤（E 系列）即拒收、警告（W 系列）僅提示。匯入時請留意：**匯入之方案會整份取代現有的自訂方案**（不是新增一個條目、也不是合併），故唯音同時最多只持有一份自訂方案；檔案大小上限為 1 MiB。匯入成功後，記得把「雙拼方案:」切到「自訂雙拼」。

## 5. 疑難排解

- **敲了兩鍵卻出全拼／沒反應**：檢查「拼音輸入種類」是否為拼音、「啟用雙拼」是否開啟、「雙拼方案:」是否選對；若選「自訂雙拼」，確認方案已匯入且通過校驗（見「雙拼方案」區塊之狀態列）。
- **想換方案**：內建兩套直接在「雙拼方案:」切換；自訂方案則重新匯入（會取代舊的）。
- **想回到全拼**：關掉「啟用雙拼」。
- **用了注音**：雙拼與注音無關——注音輸入完全不受影響；您只需以「**拼音/注音打字模式切換**」熱鍵（預設 **Control+Command+Shift+J**，即 ⌃⌘⇧J）在注音與拼音模式之間切換即可（該熱鍵可在「鍵盤設定」頁停用；若當時開著磁帶模式，這一按只會先關閉磁帶、不會切換打字模式）。
