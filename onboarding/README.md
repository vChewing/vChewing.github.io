# 新手上路

唯音輸入法（vChewing）是一款專為 macOS 研發的免費開源中文輸入法，自 2021 年底立案至今持續維護。它的核心理念很單純：**打字習慣不必為了輸入法而改變，該由輸入法來配合您。**

> **關於名字**：4.1.3 版以前，本輸入法叫「威注音」。因為「威注音」在搜尋引擎裡常被拆成「威」與「注音」、反而讓使用者在臉書與 Threads 等 SNS 找不到相關內容，才更名為「唯音輸入法」。兩者是同一款軟體。

## 為什麼可以放心安裝

- **是敢於開啟 Apple Sandbox（沙箱）保護的第三方免費 macOS 中文輸入法**：唯音被關在系統的隔離區裡，無法偷讀您電腦中的私密檔案，其他軟體也無法隨意窺探它的資料。
- **絕不主動聯網**：除非您主動在偏好設定內勾選「自動檢查軟體更新」，否則它不會聯網通訊。
- **主動揪出「安全模式」濫用者**：有些軟體（例如某些密碼管理工具）用完 macOS 的安全模式（SecureEventInput）之後忘了關閉，會導致所有第三方輸入法在選單中變灰、無法切換。唯音會主動偵測、直接告訴您是哪一款軟體造成的（macOS 15 起，系統於此情境已有所改善）。此偵測可在「開發道場」關閉。

## 我該從哪裡開始？

不必從頭讀到尾。請直接找最接近您情況的那一段。

### 依您的打字習慣

- **逐字選字（「ㄅ半」派）**：偏好設定裡有一顆逗趣的懶人包按鈕「**我姓ㄅ**」（4.5.1 版起），按一下就會把設定切換成最純粹的ㄅ半模式：逐字選字、關聯詞語、選字鍵 123456789、縱向單行選字窗。候選字順序另有「對所有單漢字候選字強制施加倚天中文 DOS 系統排序」把關（預設開啟），不受打字學習功能干擾。
- **注音組句（打一串再選）**：選字窗（田所選字窗）支援橫向多行多列與縱向排列、字型大小可自由調整，並內建滾動條；「弱輪替」（4.5.4 版起，預設開啟）會在輪替候選字將覆蓋您已手動選定的區域時自動跳過，保護您已選好的字。詳見《[使用者介面](../manual/basicUI.md)》。
- **中英混打**：至「偏好設定 → 行為設定 → 混合輸入」，勾選「啟用中英文混合輸入回退」（4.4.1 版起，預設關閉）。開啟後可直接打 `4G`、`Philia093` 這類中英夾雜的內容，不必反覆按 Caps Lock 切換輸入法。
- **CIN 表格（行列、倉頡、嘸蝦米……）**：至「偏好設定 → 磁帶設定」掛載您的 `.cin`／`.cin2` 碼表（支援從 Finder 直接拖入）即可。**請把碼表放在本機目錄**（例如「下載」），不要放在由 iCloud Drive 代管的「文件」或「桌面」，以免同步延遲導致輸入法讀不到檔案。
- **拼音輸入**（漢語拼音、通用拼音、華羅拼音、國音二式、耶魯拼音）：拼音模式下可以**省略聲調**、也可以把整個音節串一口氣打完（4.4.0 版的護摩引擎起）；追求精準時仍可照常輸入聲調。
- **需要簡體中文**：唯音原生支援簡體中文輸入。在系統設定內同時啟用「唯音-繁」與「唯音-簡」即可，且與 macOS 內建的「聽寫」功能相容。

## 安裝與初次啟用

### 系統需求

- **主流版本**：macOS 12（Monterey）以上。
- **Aqua 紀念版**：macOS 10.9（Mavericks）以上，專為仍在使用舊系統的專業環境（例如部分錄音室的 Pro Tools 設備）而設。如何區別兩者，見《[如何區別主流發行版與 Aqua 紀念版](../techdocs/AQUASPECIAL.md)》。

### 安裝步驟

1. 至[唯音輸入法官網](https://vchewing.github.io/)取得安裝檔（GitHub 或 Gitee 下載均可）：可選 `.pkg` 安裝檔或 `-alternative.zip` 安裝包。
2. 若下載的是 `.zip` 包：解壓縮後執行「唯音輸入法安裝程式」；Aqua 紀念版則執行「唯音紀念版安裝程式」。
3. 安裝後，系統可能提示啟用第三方輸入法，請點選「啟用」。
4. 需要繁簡雙模式的話，請在系統設定中同時啟用「唯音-繁」與「唯音-簡」。

詳細步驟（含切換、停用與卸除）見《[安裝/啟用/切換/停用/卸除](../manual/install_uninstall_enable_disable.md)》。

## 裝好之後，建議先做這三件事

1. **找到偏好設定**：從輸入法選單最頂端進入「偏好設定」（4.5.2 版起已移到頂端，方便查找）。
2. **開啟更新檢查**：在「一般設定」勾選「自動檢查軟體更新」，第一時間取得新功能。
3. **對號入座**：回到上一節，把設定調成最符合您習慣的樣子。偏好設定超過 110 個選項，翻頁找很痛苦——在偏好設定畫面按 ⌘F 即可用關鍵字直接搜尋（4.4.7 版起支援）。

## 支持唯音

唯音完全免費且開源：沒有廣告、沒有資料收集，也沒有隱藏收費。專案由獨立開發者維護，贊助會直接用於 Apple 開發者會員年費等開發支出，並直接影響他下一季能投入多少心力。若唯音讓您的打字更順手，歡迎見《[如何贊助唯音輸入法的開發](../SPONSOR_ME.md)》一文。
