#### 4.9.2 版針對 4.9.1 版更新了下述內容：

- 懶人包總結：修復了 Shift 鍵偶發切換不了中英、事後按鍵仍以英文原樣送出的故障；另修復注音狂打模式下刪除尚未完成拼寫的讀音時，漢語拼音工具提示殘留的故障。
- 修正：[所有發行版] 解決了注音狂打模式下「在手動刪除掉尚未完成拼寫的讀音的那一刻可能會出現漢語拼音工具提示殘留」的故障。
- 修正：[所有發行版] 修復了「Shift 鍵偶發切換不了中英、此後按鍵卻仍以英文原樣送出」的故障；病根在唯音內部「打字會話副本」的分配與回收方式，現已改寫。
  - 症狀與情境：其他軟體短暫搶過焦點（截圖工具、暫時切換輸入法的腳本等）之後最易遇上。右 Shift 的中英切換提示照樣出現，客體卻仍收到英文；按一次 CapsLock、或再切換一次客體應用，即可恢復。
  - 緣由：每個客體應用各對應一枚輸入控制器，而輸入控制器原以「世代奇偶」固定分配到兩份共用的會話副本之一；同奇偶的兩枚可能共用同一份，其中一枚短暫搶焦後退場時，該副本的客體綁定會被清空、或仍指著已退場的那一枚，於是往後的按鍵在送進輸入法之前就被擋下。
  - 現況：會話副本改由一個至多四份的會話池、以輸入控制器自身的位址配發專屬副本；每收到一次輸入事件，即把該副本的客體綁定指回當下送事件的客體；副本的回收改看控制器是否仍存活，不再倚賴「停用三秒後之延遲拆除」。
- 辭典：[所有發行版] 例行語彙資料更新。
