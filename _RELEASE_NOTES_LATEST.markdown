#### 5.0.5 版針對 5.0.4 版更新了下述內容：

- 懶人包總結：改良了「成對出現的標點符號」的輸入體驗；修復了在藉由系統監視程式監聽唯音輸入法偵錯訊息時的打字遲鈍的故障。
- 體驗：[所有發行版] 改良了「成對出現的標點符號」的輸入體驗：
  - 從 `\` 或 `Shift+\` 選入 `【】`、`《》` 等成對標點時，會拆成左右兩個可各自編輯的單邊標點，並將游標置於兩者之間；可直接在括號內繼續輸入。
  - 之後以輪替或重新選字變更其中一邊時，相鄰的另一邊會同步成對應的標點。以普通的左右方向鍵試圖越過整對標點時，會先拆對、置中，再吃掉該步。
  - 以 Tab／空白鍵輪替到完整成對標點時仍保持整對，不會逕行拆開，除非已經被拆開。
  - Shift（標記游標）與 Option／Command（按節點跳）也不會觸發拆對。
  - 半形標點模式現在也提供 `[]`、`{}`、`()`、`<>` 等成對候選，並支援同樣的拆對、置中與同步行為。
  - 縱排書寫時「強制轉換標點為縱排形式」亦已納入；拆對與同步不會破壞縱排標點。
  - 目前範圍限於組字區內相鄰的成對標點；至於巢狀（如 `【「」】`）或跨內容與逐字選字模式則不在該特性的服務範圍內。若兩邊不是同一組索引鍵（例如少按了 Shift）的話，原則上無法觸發該特性。
- 修復：[所有發行版] 修復了在藉由系統監視程式監聽唯音輸入法偵錯訊息時的打字遲鈍的故障。
- 辭典：[所有發行版] 先鋒語料庫移除了標點符號語料。唯音輸入法原廠標點符號語料現由先鋒引擎的倉庫負責維護。另外，與標點符號索引用的 key 的特徵已經由「包含 `_punctuation`」改成「包含 `_punct`」。如果您此前有藉由使用者語彙資料檔案修改過標點符號定義的話，雖然這些檔案仍會被讀入，但開發者建議您將使用者片語檔案當中的 `_punctuation` 批次取代為 `_punct` 以改善這些使用者片語檔案的載入效能。
- 辭典：[所有發行版] 例行語彙資料更新＆複元圖資料更新；全字庫資料更新至 2026-11-16。
