#### 5.0.3 版針對 5.0.2 版更新了下述內容：

- 懶人包總結：緊急修復選字窗效能退步之故障（會妨礙狂拼模式的正常使用）；「就地加詞」與「候選詞升權／降權」現在會在寫入之後自動複查是否真的生效。
- 修復：[所有發行版] 緊急修復了與選字窗效能有關的故障。該故障發生在每次給選字窗籌備資料的時間點。該故障乃此前 5.0.0 版修復另一個問題時不慎引入。該故障會嚴重妨礙狂拼模式的正常使用。
- 行為：[所有發行版] 「就地加詞」與「候選詞升權／降權」現在會在寫入之後自動複查是否真的生效：若發現既有的打字學習記憶、或辭典內同分的舊記錄會使這次操作失效，會自動清掉該記憶、或把該筆記錄重寫成最新，使這次操作確實生效。
  - 「刪詞／濾除」不在此列：其成效當場可見，行為照舊。
- 辭典：[所有發行版] 例行語彙資料更新＆複元圖資料更新。
