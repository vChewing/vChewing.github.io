#### 4.8.4 版針對 4.8.3 版更新了下述內容：

- 懶人包總結：中英混打模式的讀音判定新增可切換之選項「依槽序鍵入判定讀音」（預設開啟），供已習慣舊制判定者切回舊制行為；選字窗UI美工細節調整。
- 體驗：[所有發行版] 中英文混合輸入回退模式（也就是注音中英文混打模式）新增一個**預設開啟**的可選項「依槽序鍵入判定讀音」。
  - 該選項位於偏好設定的「行為設定」頁，緊鄰「啟用中英混合輸入回退」（位於其正下方）。
  - 本選項決定混打模式如何判定「整段輸入是否為一個讀音」。開啟時（預設）沿用 4.8.3 版引入的判定方式：以「按鍵是否依正規鍵序敲成了一個讀音」為準；關閉後則回到該判定方式引入之前的舊制行為。
  - 若您希望在中英混打時維持聲韻並擊等「不需要嚴格按照順序敲注音」的特性，請關閉本選項；否則請維持開啟。
  - 關閉本選項後：兩字母的純英文字母內容（例如 `ls`、`ln`）不再被視為英文意圖、而會重新被當作注音吸收；酷音大千26鍵的 `qquu` 這類合法多寫編碼也不再被吸收為單一讀音，而會留在英數緩衝、於敲空白鍵時被如實送出。
  - 本選項不影響「啟用中英混打模式的英數閂滯狀態」選項自身的判定。
- 體驗：[所有發行版] 選字窗UI美工細節調整。
- 辭典：[所有發行版] 例行語彙資料更新。
