#### 4.8.7 版針對 4.8.6 版更新了下述內容：

- 懶人包總結：修復了「中英文混合輸入回退模式」與「注音狂打」並用時會遞交未經確認的臆測內容的故障；有 CMD 鍵參與的熱鍵現在會先遞交組字內容、再將該熱鍵交還給系統；修補了選字窗縮放動畫的美術瑕疵。
- 修復：[所有發行版] 修復了「中英文混合輸入回退模式」與「注音狂打」同時啟用時、部分退出組字的路徑會遞交**未經使用者確認的臆測預覽內容**的故障。
  - 故障形態：該狀態下的副駕選字窗會以前方讀音臆測出候選詞，而遞交時把該臆測連同英數緩衝一併送出（例如敲 `su` 後按符號選單鍵，遞交的是 `你你泥su`），與組字區內實際顯示的內容不符；此外，英數緩衝的原文也會被重複插入一次。
- 修復：[所有發行版] 修復了選字窗在自身尺寸調整時的動畫過程中的一些美術瑕疵。
- 修復：[所有發行版] 更新了上一個版本忘記更新的、被輸入法同捆的熱鍵指南說明資料。
- 修復：[所有發行版] 給唯音輸入法同捆的五個自訂 Ukelele 佈局補上了與「有 CMD 鍵參與的熱鍵」有關的 Raw Key Char Map 行為。
- 行為：[所有發行版] 有 CMD 鍵參與的熱鍵被觸發時，輸入法現在會先遞交內容、再將熱鍵交還給系統。另：Chrome 與 Safari 受 W3C 規範之疏忽的影響，無法響應 Ukelele 鍵盤佈局當中對「有 CMD 鍵參與的熱鍵」專屬的 raw key char map，導致某些熱鍵可能會在唯音輸入法啟用時失效（詳見 GitHub `w3c/uievents/issues/420`）。臨時躲開該問題的方法是在「唯音偏好設定 -> 鍵盤設定 -> 基礎鍵盤佈局」當中使用「ABC」佈局，且該方法會犧牲掉螢幕模擬鍵盤的視覺傳真體驗（明明敲的是注音，但模擬鍵盤會顯示成美規英文佈局）。
- 行為：[所有發行版] 英文本地化以及原始碼倉庫對注音聲調「陰平」的稱謂現在被統整為「First Tone」。
- 研發：[所有發行版] 統整了 LibVanguard 原始碼套件當中的與 InputHandler 和 Session 有關的單元測試條目的分類與命名。
- 辭典：[所有發行版] 例行語彙資料更新。
