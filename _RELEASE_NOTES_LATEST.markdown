#### 4.8.2 版針對 4.8.1 版更新了下述內容：

- 懶人包總結：大幅度提升了對使用者片語資料的載入速度。原廠詞庫大勘誤、持續清掃 LibTaBE 歷史積誤，亦同時確保至少五千多筆四字成語有被收錄。
- 體驗：[所有發行版] 當載入使用者片語資料時，如果某一筆片語資料的讀音串當中只有純注音的話，將不再累贅地走「拼音轉注音」的過程。對於僅使用注音來標注詞語讀音的使用者片語檔案而言，這個行為改變使得整個檔案的解讀速度快了 55 倍。這允許唯音輸入法迅速載入多達幾萬筆使用者片語資料。
- 辭典：[所有發行版] 例行語彙資料更新。本次更新對原廠詞庫當中源自於 LibTaBE 的那部分做了大勘誤。本次語彙資料更新亦同時確保至少五千多筆四字成語有被收錄。
