#### 5.1.0 版針對 5.0.6 版更新了下述內容：

- 懶人包總結：修復了切換鍵盤排列後螢幕鍵盤不跟著換、以及「精業」排列沒有專屬佈局的故障；並修復了只敲聲母時簡拼副駕選字窗的遲鈍。
- 修復：[所有發行版] 鍵盤排列與螢幕鍵盤佈局不同步的兩樁故障：
  - 在偏好設定切換排列（注音、拼音、雙拼）之後，客體端仍停在先前那個 Ukelele 佈局。此故障現已修正；同梱的六份 `.keylayout` 也改以散檔安裝、確實註冊（原先放在一個從未被註冊的 bundle 裡）。
  - 「精業」排列此前沒有專屬佈局，選了它之後按鍵位置停在上一個排列（看起來像是在用偽精業）。現補上精業專屬佈局：ㄧ／ㄨ／ㄩ 在 `-`／`[`／`'`，ㄦ 在 `=`，數字鍵 4／5／7 亦已釋出。
- 修復：[所有發行版] 注音狂打時只敲了未完成的聲母，簡拼副駕選字窗會把全字庫（CNS）候選整批拉進來（單次按鍵可達數千筆，中位數延遲自 2.35 ms 漲至 17.5 ms）。該視窗的全字庫供給現以 200 筆為上限；一般選字窗不受此限。
- 修復：[所有發行版] （僅繁體中文）「原廠辭典僅傳回符合全字庫讀音的結果」此前拿「查詢」而非「詞條自身的讀音」來判定：只敲一半時一筆都濾不掉，候選過多時又整個跳過；旁邊的「濾除掉與輸入模式不相符的漢字候選」在同樣情形下還會把候選清空。兩者現皆以詞條自身的讀音判定。
- 體驗：[所有發行版] 注音簡拼的副駕選字窗現在以整詞候選領頭。
- 行為：[所有發行版] 若您在偏好設定指定了外部的原廠辭典檔案、而它缺少某些資料表（例如只有簡體或只有繁體、或沒有全字庫／GBEX），現在會逐表回退到內建辭典；此前該表會查不到任何東西。
- 辭典：[所有發行版] 例行語彙資料更新＆複元圖資料更新。
