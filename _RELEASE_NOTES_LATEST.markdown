#### 5.0.0 版針對 4.9.2 版更新了下述內容：

- 懶人包總結：「在」「再」這類同音字的取捨現在會依前後文動態擇優；新增「候選字順序覆寫」，可自訂單一讀音下的候選順序。
- 體驗：[所有發行版] 同音單字的取捨現在會依前後文動態擇優：例如「在」與「再」這類共用同一讀音的單字，不再只憑各自的單字頻率，而會連同前後詞句一併計分。
- 體驗：[所有發行版] 新增「候選字順序覆寫」：可指定單一讀音之下候選字詞的排列順序，於「使用者片語辭典」編輯器新增的「候選順序」分頁內編輯。
  - 列出的候選會依序排到最前面，其餘候選維持原本的相對順序接在其後；此表只調整順序，不新增辭典內查無的候選。
  - 本表之優先權高於「倚天中文 DOS 候選序」；逐字選字模式與磁帶模式下不套用。同一讀音寫了多行時，以最後一行為準。
- 行為：[所有發行版] 調整了打字學習記憶的效力與時間流逝的關係變化效力。
- 修復：[所有發行版] 修復了簡拼（狂打）整詞候選的名次在不同次啟動之間可能不一致的故障。
- 修復：[所有發行版] 修復了選字窗單個候選字詞的預留畫布空間寬度計算錯誤的故障。這會導致一些與佈局有關的繪製行為失常。
- 修復：[所有發行版] 中英混打的「英數閂滯狀態」開啟時，`Shift+?` 的問號現在改由「半形標點模式」偏好決定半形或全形；英數緩衝非空時仍維持既有的半形語義。
- 研發：[所有發行版] 組句計分之 n-gram 改依前驗詞鏈長度加權。
- 研發：[所有發行版] 改良了選字窗後端資料池模組的記憶體 heap 佔用。
- 研發：[所有發行版] 若原廠辭典係取自輸入法程式封包本體、而非使用者指定之外置原廠辭典，現在會在載入時省略部分資料合規檢查，大幅縮短載入耗時。
- 辭典：[所有發行版] 例行語彙資料更新。
