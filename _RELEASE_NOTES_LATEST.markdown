#### 5.0.2 版針對 5.0.1 版更新了下述內容：

- 懶人包總結：修復了拼音狂打模式在有全拼上下文時對簡拼的副駕選字窗的選字行為的有效性故障；修復了與農曆日期格式有關的敲字代令行為故障。
- 修復：[所有發行版] 緊急修復了拼音狂打模式在有全拼上下文時對簡拼的副駕選字窗無法使用「Shift+選字鍵」選字的故障。
- 修復：[所有發行版] 藉由敲字代令試圖輸入農曆日期時，現在不會再遺漏結尾的「日」字。
- 辭典：[所有發行版] 例行語彙資料更新＆複元圖資料更新。
