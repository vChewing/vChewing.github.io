#### 5.0.6 版針對 5.0.5 版更新了下述內容：

- 懶人包總結：修復了「在偵測到 SecureEventInput 情形時的警示視窗排版坍縮無法顯示全文」的故障；修復了 Aqua 紀念版因原廠資料讀取方法失誤而無法正常運作的故障。
- 修復：[所有發行版] 修復了「在偵測到 SecureEventInput 情形時的警示視窗排版坍縮無法顯示全文」的故障。該視窗的解說文字亦經過重新整理。
- 修復：[Aqua 紀念版] 修復了與原廠標點符號資料讀取有關的一處故障。該故障會導致輸入法無法正常啟動。
- 辭典：[所有發行版] 例行語彙資料更新＆複元圖資料更新。
