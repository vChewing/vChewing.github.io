#### 4.8.3 版針對 4.8.2 版更新了下述內容：

- 懶人包總結：修復選字窗橫向展頁時可捲動範圍不隨字號變化的故障；中英混打模式新增「英數閂滯狀態」選項（預設關閉），並改良英文判定：短英文如 `ls` 不再被吞、動態注音排列不再被誤判。
- 修復：[所有發行版] 修復了選字窗在橫向佈局（此時展頁方向是縱向）的展頁狀態下的可捲動區域的尺寸「沒能依照選字窗文字大小的改變而改變」的故障。
- 體驗：[所有發行版] 中英文混合輸入回退模式（也就是注音中英文混打模式）新增一個**預設關閉**的可選項「啟用中英混打模式的英數閂滯狀態」。
  - 該選項位於偏好設定的「行為設定」頁，緊鄰「啟用中英混合輸入回退」。
  - 開啟後，一旦該模式把某段英數內容判定為英文，這個判定結果就會被「閂滯」住：其後敲下的每一顆可列印英數字元都會立刻送交給當前的輸入客體，不再於輸入法內累積等待確認，直到您按下解除鍵為止——這讓「一次打一整串英文」的手感接近英數輸入模式。
  - 該閂滯狀態的進入與解除時各會顯示一則約一秒半的浮動提示，該提示不佔用內文組字區，故連續打字時依然看得見。
  - 該閂滯狀態的解除鍵為 Enter、BackSpace、Delete、Esc 與 Option+BackSpace。其中 BackSpace、Delete 與 Esc 只解除閂滯、既不送出也不刪除任何字元，因為先前的內容早已遞交出去、輸入法無從回收。
  - 此選項不會把唯音切換成英數模式：唯音仍處於中文打字模式，只是混打判定結果被固定住了而已；且「閂滯」只作用於英文，不存在「閂滯於中文」的狀態。
  - 若您感受不到「判定結果被固定」所帶來的差別，建議維持關閉。
- 體驗：[所有發行版] 中英文混合輸入回退模式（也就是注音中英文混打模式）的英文判定獲得改良。該模式現在改以注拼引擎自身對「按鍵是否依正規鍵序敲成了一個讀音」的檢定結果為準，因而有兩處變化：
  1. 凡是「在當前注音鍵盤排列下不可能依正規鍵序敲出來」的純英文字母內容，現在都會被視為英文意圖、以 ASCII 形式如實遞交，不再被當作某個漢字的讀音吸收。此判準對僅兩個字母的內容亦生效——例如 `ls`、`ln`、`mv` 這些常用的命令列字串此前會被吃掉，現在則會如實送出。
  2. 酷音大千26鍵、倚天26鍵等動態注音排列的合法鍵碼不再被誤判為英數內容。這類排列的合法鍵碼本就會由同一顆按鍵先後改寫同一個注音符號槽（例如酷音大千26鍵的 `qquu` 代表「ㄅㄚ」），故其按鍵數目本就會多於所佔用的槽數；此前這個落差被當成「使用者其實在打英文」的證據，導致整段內容滯留於組字區、最終於敲空格鍵時被當成英文送出去。
