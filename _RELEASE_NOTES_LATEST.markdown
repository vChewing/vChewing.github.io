#### 4.8.5 版針對 4.8.4 版更新了下述內容：

- 懶人包總結：新增「唯音輸入法配置助手」——以最少四個步驟的問卷迅速產生現成的配置包、直接匯入唯音的偏好設定，新手不必再自行翻找一百多個選項；中英混打模式的空白鍵現貫徹「空格鍵對內文組字區的行為」偏好；修復了組字狀態下 F1～F20 按鍵會令未遞交內容消失的故障。
- 體驗：[所有發行版] 於「一般設定」頁新增按鈕「**新手推薦：開啟快速配置助手**」與「點此從剪貼簿匯入（由配置助手生成的）配置資料」按鈕。
  - **問卷動線**：先問您原本慣用哪套輸入法、以及您習慣怎麼打字，其後即據此端出一組**起始配置**（多數使用者套用該組即可收工）。整份問卷只需四頁；想逐項微調者另有完整版，且隨時可跳到摘要。問卷產出的東西是一份又稱「配置包」的 JSON 設定資料。
  - **官方網站版**：「開啟快速配置助手」按鈕會檢查輸入法是否有同捆離線版配置助手，並請您選擇使用該離線版本、還是使用官方網站的最新版本；後者可能僅適用於最新版的輸入法。
- 體驗：[所有發行版] 「一般設定」頁面的一些選項被移動至「行為設定」頁，以免「一般設定」頁過於擁堵。
- 修復：[所有發行版] 修復了辭典檢索快取的作廢機制對 POM 等附屬資料快取內容失靈的故障：此前更換詞庫資料、載入使用者符號表、或載入磁帶（CIN）檔案之後，已查詢過的讀音會在該次輸入法行程內持續回傳變更前的結果。這在使用上的表徵是：在偏好設定內匯入自訂詞彙後、未重新啟用輸入法即打字時，新詞彙不生效。
- 修復：[所有發行版] 修復了「組字區內尚有未遞交的讀音或注拼內容時，敲下 F1～F20 功能鍵會令該內容消失、且把該按鍵自身的不可列印字元寫進當前文件」的故障。
  - 敲 `su3` 後按 F5、再按 Return，此前得到的是控制字元而非「你」。
  - 修復後：輸入法持有未遞交內容時，功能鍵一律由輸入法就地攔截，且會發出系統提示音——免得您無從分辨「輸入法刻意攔截」與「功能鍵故障」。
  - 例外：`Fn` + 字母之類的系統熱鍵（如表情符號選擇器 `Fn+E`）不受影響；未遞交內容為空時，功能鍵亦照舊放行給系統。
- 修復：[所有發行版] 中英混打模式下的空白鍵現在會貫徹「空格鍵對內文組字區的行為」這一偏好設定。
  - 修復前：該路徑此前不讀取該偏好設定，故明示「插入空格」者敲空白鍵仍得到「自動切分」——英數緩衝的尾鍵被送進注拼槽（`apple` 得到 `appl` 加注音ㄍ、`school` 得到 `schoo` 加注音ㄠ）。
  - 修復後：該偏好設為「插入空格」時，空白鍵與 Shift+空白鍵同義。偏好維持預設者**刻意不變動**，合法注音（例如 `su3`）與拼音路徑亦不在本次範圍。
- 行為：[所有發行版] 當輸入法由外部途徑讀入 JSON 格式的偏好設定資料時，帶有副作用之偏好鍵原本一概不會被觸發，現已於匯入後補上一次「和解」（辭典資料重載、語音服務刷新等亦隨之一併生效）。
- 辭典：[所有發行版] 例行語彙資料更新，並移除「底」字的「ㄉㄜ・」又音及其相關字詞，以免這類又音詞條在特定讀音下劫持組句結果。
