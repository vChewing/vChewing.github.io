#### 4.8.6 版針對 4.8.5 版更新了下述內容：

- 懶人包總結：「狂拼模式」正式升級為「拼音狂打」與「注音狂打」；修復了中英混打模式下把「空格鍵對內文組字區的行為」設為「插入空格」時無法鍵入陰平聲調讀音的故障；修復了打字學習記憶系統的一處記錄條件過嚴的故障。
- 修復：[所有發行版] 修復了 4.8.5 版之一處回歸：中英混打模式下，將「空格鍵對內文組字區的行為」設為「插入空格」者，於注音尚未鍵入聲調時按空白鍵（該鍵之語意為一聲）會被當成英數遞交、該讀音因而消失，以致一聲字無法完成（例如打 `su` 再按空白鍵，得到的是 `su ` 而非「妮」）。偏好維持「叫出選字窗」或「就地輪替候選字」者不受影響。
- 修復：[所有發行版] 修復了打字學習記憶系統的一處故障：在較長的句子中組出多音節詞之後，若把游標移進該詞、只針對其中某一個讀音就地改選候選字，該次修正不會被記憶下來（下次重打同樣的句子仍會得到原先的錯誤結果），非得繞路——先把游標移回該詞的起點、就地改選整個詞，再前移改選該字——才記得住。這是因為該記憶的記錄條件過嚴：詞節點在套用修正前已被拆散，寫出的記憶鍵因而對不上日後的文脈；且文脈加分只維持一瞬、下一顆按鍵就會被丟掉。現已修正，該類修正得以正確記錄並留存。
- 修復：[所有發行版] 修復了副駕選字窗之候選排序的一處故障：當原廠辭典對某段未完成讀音沒有對應的詞條時，組句引擎會以該讀音的字串本身作為墊底候選，而它此前被釘在候選清單最頂端，以致簡拼所得的漢字詞（例如 ㄍㄋㄋ 得「狗男女」「姑奶奶」「告奶奶」）一律排在它之下。現在改為：該墊底候選若確實只是讀音本身，則降入排序段、不再釘頂（仍可選取），漢字詞因而得以排在其上。
- 體驗：[所有發行版] 唯音輸入法的拼音「狂拼」模式正式更名為「**拼音狂打**」，並新增注音側的「**注音狂打**」——兩者為各自獨立的開關。
  - 狂打模式會利用當前尚未完成拼寫的讀音、以副駕選字窗的形式呈現你可能會想提前鍵入的候選字詞。副駕選字窗的選字鍵需要同時摁 Shift 才會生效。
  - 拼音狂打承襲此前的狂拼模式的行為，原廠預設值仍為「啟用」狀態。原「啟用狂拼模式（連續拼音打字）」之偏好設定值會自動由「啟用拼音狂打（連續拼音打字）」承接。
  - 注音狂打的原廠預設值為「停用」狀態，以免挑戰到大部分注音打字使用者的習慣。
  - 注音狂打的特色：
    - 自動切注音音節（當前音節已打完、而下一鍵屬於新音節時自動成音，不必逐音節敲聲調）與注音簡拼（只敲聲母亦可，候選窗即時列出整詞候選、長詞優先，例如 ㄍㄋㄋ 得「狗男女」等以這三個聲母輪流開頭的三字漢字詞）。
    - 相比拼音狂打而言，注音狂打不會用 Space 空格鍵確認位於當前副駕選字窗的高亮候選字詞，因為注音模式下能輸入陰平聲調的按鍵只有空格鍵。
- 行為：[所有發行版] 中英文混合輸入回退模式（也就是注音中英文混打模式）的行為變化：
  - 中英文混合輸入回退模式現在會將 ASCII 內容顯示在組字區內，更趨近於華碩智慧輸入法的 UI 呈現行為。如果您同時啟用了注音狂打特性的話，則 ASCII 內容可能會顯示在副駕選字窗內（除非當前輸入法狀態內容不滿足副駕選字窗的顯示條件）。
  - 如果您開啟了拼音並擊特性的話，中英文混合輸入回退模式所顯示的尚未完成拼寫的注音內容現在也會被轉成漢語拼音（純 ASCII 拼寫格式）。
  - 中英文混合輸入回退模式的「依槽序鍵入判定讀音」現在也涵蓋含聲調的輸入：此前該判定只檢查純英文字母（帶聲調數字者一概不查），故靜態注音排列下「按鍵數目恰等於所佔槽數」的舊式計數啟發法仍會誤收亂序鍵入的讀音（例如 `oj4` 會被當成「未」）。修後此類內容一律如實遞交 ASCII（`oj4 `）；順序正確者（例如 `jo4`→「未」）不受影響。關閉本偏好者行為不變。
- 辭典：[所有發行版] 例行語彙資料更新。
