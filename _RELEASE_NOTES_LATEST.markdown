#### 4.8.1 版針對 4.8.0 版更新了下述內容：

- 懶人包總結：中英混打模式的英數內容工具提示現會隨文脈挪位，並可用 Option+BackSpace 一次清空尚未遞交的英數/尚未插入組句引擎的讀音；「以聲調鍵覆寫游標身後讀音」的上下文提示現可於偏好設定內關閉；修復了就地加詞與打字學習記憶模組搶佔檔案寫入的死鎖故障、以及加詞或控頻後未能立即生效的故障。
- 體驗：[所有發行版] 中英文混合輸入回退模式（也就是注音中英文混打模式）新增兩處體驗改良：一、用以顯示當前敲入的英文暫存拼寫資訊的工具提示的視窗現在會隨著打字時的文脈狀態挪動自身的位置；二、現在允許使用者藉由「Option+BackSpace」熱鍵組合來一次性清空那些尚未被插入組句引擎/尚未被遞交出去的內容。
- 體驗：[所有發行版] 現在可以在唯音輸入法偏好設定的「行為設定」頁面手動關掉「以聲調鍵覆寫位於游標身後的讀音」時的上下文工具提示訊息。
- 修復：[所有發行版] 已知唯音輸入法 4.4.0 ~ 4.7.x 會在就地加詞時使用錯誤的 Actor 解鎖順序執行檔案寫入操作，會與 POM 打字學習記憶模組的資料寫入行為撞車引發死鎖。4.8.0 無心差柳地徹底阻止了這個故障的發生，但沒有根除該問題的病灶。這次更新徹底剷除了這個病灶。
- 修復：[所有發行版] 徹底修復了「在加詞或控頻之後，沒能立刻在當前組字區內生效」的故障。該故障在此前依概率發生，但在 4.8.0 版則是 100% 發生。
- 辭典：[所有發行版] 例行語彙資料更新。
